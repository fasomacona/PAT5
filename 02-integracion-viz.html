5.2 Integración de visualizaciones y funcionalidades analíticas

La interfaz debe permitir filtrar, comparar y entender resultados del modelo sin salir de la aplicación. Reutilizamos Plotly (Tema 2) y conectamos predicciones del Tema 3.

1. Gráficos Plotly en Streamlit

import plotly.express as px
import streamlit as st

fig = px.bar(df.groupby("ciudad")["monto"].sum().reset_index(),
             x="ciudad", y="monto", title="Ventas por ciudad")
st.plotly_chart(fig, use_container_width=True)

3. Conectar un modelo entrenado

import joblib
import numpy as np

@st.cache_resource
def cargar_modelo():
    return joblib.load("models/modelo_ventas.joblib")

modelo = cargar_modelo()
features = st.sidebar.slider("Experiencia (años)", 0, 30, 5)
pred = modelo.predict(np.array([[features, ...]]))
st.success(f"Salario estimado: ${pred[0]:,.0f}")

4. Principios de diseño de dashboards

  • Primero KPIs, después detalle.
  • Filtros globales en sidebar.
  • Una pregunta de negocio por sección.
  • Evitar más de 5–6 gráficos en la vista principal.
  • Incluir notas sobre calidad de datos y fecha de actualización.
