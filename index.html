y Proyecto Práctico

Integra todo lo aprendido: programación avanzada, manipulación de datos, visualización, estadística, modelado predictivo y bases de datos en una aplicación real de analítica.

Comenzar teoría Ir a la práctica integradora

¿Qué aprenderás en este tema?

Este tema cierra la asignatura. No se trata solo de escribir scripts sueltos: construirás un flujo completo de analítica y lo expondrás en una aplicación (Streamlit o Flask) con visualizaciones interactivas, conectada a datos y, opcionalmente, a modelos predictivos.

Competencias específicas

  • Desarrollar aplicaciones de analítica de datos con Python y herramientas web.
  • Integrar visualizaciones y funcionalidades analíticas en aplicaciones.
  • Diseñar, implementar y presentar un proyecto práctico integrador.
  • Aplicar de forma conjunta los temas 1–4 en un caso de uso coherente.
