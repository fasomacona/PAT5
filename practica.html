💻 Práctica integradora: de los datos a la aplicación

Esta práctica es el cierre del curso. Construirás un pipeline completo y una app Streamlit usando un dataset de empleados/ventas, aplicando explícitamente competencias de los temas 1 al 5.

📦 Material incluido

⬇️ Notebook integrador ⬇️ Dataset CSV ⬇️ App Streamlit

Notebook: notebooks/practica_tema5_integradora.ipynb
App: app/app.py · Datos: data/empleados_ventas.csv

Mapa de la práctica por tema

FaseTemaQué harás
A. Carga y limpieza1Pandas, nulos, duplicados, tipos, features
B. Exploración visual2Seaborn/Plotly, distribuciones, correlaciones
C. Estadística y modelo3Pruebas básicas, regresión/clasificación, métricas, CV
D. Persistencia4Guardar tablas limpias en SQLite y consultar
E. Aplicación5Dashboard Streamlit con filtros, KPIs, gráficos y predicción
F. Presentación5README + conclusiones del proyecto

Caso de negocio propuesto

Empresa: compañía con personal en varias ciudades.
Objetivo 1: entender drivers del salario y predecir salario (regresión).
Objetivo 2 (opcional): clasificar si un empleado está en el segmento de alto desempeño / alto salario.
Entrega de valor: dashboard para RR.HH. o dirección con filtros por departamento y ciudad, más una herramienta simple de estimación.

Cómo ejecutar

cd tema5-aplicaciones-analitica
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 1) Análisis en notebook
jupyter lab
# Abrir notebooks/practica_tema5_integradora.ipynb

# 2) Aplicación
streamlit run app/app.py
📌 Criterios de evaluación de esta práctica
  • Pipeline reproducible de limpieza → modelo → app.
  • Uso explícito de técnicas de los temas 1–4.
  • App usable (filtros, métricas, al menos 2 visualizaciones, predicción).
  • Documentación clara (README y celdas markdown).
